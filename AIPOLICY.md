# AI Policy for Indige

*Last updated: 11/13/2026 · Developer: Kenny Solorio*

## Why this policy exists

Indige works with language that belongs to a community. Using AI in this project raises real questions about data sovereignty, accuracy, and trust. This policy says exactly how AI was and wasn't used, so anyone can check my work and hold me to it.

## Principles

This project follows the spirit of the CARE Principles for Indigenous Data Governance.

- **Collective benefit:** the app exists to support language learning for the community and learners, not to extract value from the language.
- **Authority to control:** the dictionary's author and the community decide how their content is used, changed, or removed.
- **Responsibility:** I'm accountable for what's in the app and how it was built, including the parts AI helped with.
- **Ethics:** I choose not to use AI on language content, even where it would be technically possible.

## Where AI was used

| Area | AI involvement |
|---|---|
| App code | Claude (Anthropic) helped write, debug, and explain code. I review it before using it. |
| Documentation | Claude helped draft the README, privacy policy, and this policy. I edited and approved them. |
| Learning | Claude acted as a mentor while I learned mobile development. |

## Where AI was not used

- Creating, translating, correcting, or evaluating any language content
- Choosing which words or meanings are "right"
- Training or fine-tuning any model on the dictionary
- Any feature inside the app. The app contains no AI features and makes no network calls to AI services.

## What AI saw

In early development, I shared screenshots during debugging that contained a small number of dictionary entries, plus the database structure. I should have kept those out, and I now keep all dictionary content out of AI tools.

## Commitments

1. Dictionary content stays out of AI tools.
2. The dictionary stays out of the public code repository.
3. If AI use on this project changes, I'll update this policy before the change ships.
4. If the dictionary's author or the community asks me to change how AI is used, I'll do it.
5. I'll respond to concerns about this policy: indigeapp@duck.com

## Review

I'll review this policy every time I publish an update to the code base and before each update release.
